# GetMedia 隐私说明

洛尘（以下称"我们"）是 GetMedia（Android 应用和网页端）的运营者。本说明告诉你：我们收集什么、为什么收集、放在哪里、保存多久，以及你可以怎么处理。

## 1. 我们收集哪些信息

### 1.1 账号信息
- **登录名**：你注册时自己起的名字。
- **密码**：我们只保存经过单向加密（哈希）的结果，不保存明文，也无法查看你的密码。
- **恢复码**：只保存其校验值，不保存明文。
- **同意记录**：你同意用户协议和隐私说明的版本和时间。

### 1.2 设备与登录信息
- 设备型号、系统版本、应用或网页版本、渠道（Android 或网页）。
- 登录时间、最近登录的 IP 地址、会话的创建和最近使用时间。
- **每天最多一次的活跃信息**：版本、系统、设备型号，用于了解有多少人在使用以及修复兼容问题。

### 1.3 你主动提交的反馈
当你使用"联系作者"，我们会收到你填写的文字、你选择上传的图片（最多 3 张）、你填写的联系方式（可选），以及在你勾选"附带诊断信息"后发送的诊断内容。你可以在发送前点击"查看将发送的内容"，看到将会发送的全部字段。

诊断内容只包含：应用或网页版本、系统、设备型号、渠道，以及最近若干步骤的状态码、耗时和阶段。**不包含**密码、Cookie、登录令牌，也不自动包含你提取的链接或分享文本。

我们会清除图片中的位置等元数据（EXIF）。请不要在文字或图片中提交密码等敏感信息。

### 1.4 网页端
网页端使用必要的会话 Cookie 保持登录，不使用广告或第三方统计。

### 1.5 我们不收集的信息
手机号、真实姓名、身份证件、通讯录、短信、精确位置、设备唯一标识（如 IMEI）、你设备上的音频与视频文件内容。**你在手机上提取的音频与视频只保存在你自己的设备上，不会上传。** 例外是在网页端提取的条目：为了让你在网页里直接播放和缓存，服务器可能保存一份文件（见 §1.7）。

### 1.6 曲库清单备份（可选，默认开启）
为便于你重装或换机后恢复，我们会把曲库清单压缩后保存在服务器：标题、博主、平台、视频 ID、分 P、类型、格式、时长、文件大小、来源链接、入库时间、收藏、所属类别、播放列表及顺序，以及你为条目改过的名称。

备份只包含**本机有文件的条目**，以及你在本机做过的整理（收藏、类别、播放列表顺序）。"只在服务器、本机缺文件、也没整理过"的条目不会进备份——它们本来就在服务器上，重装后同步即可取回。

**不包含**：音频/视频文件本身、文件在本机的路径、封面地址、平台 Cookie 与登录凭据、设备标识。

每账号保留最近 3 份，每份压缩后不超过 512 KiB。你可以在"我的 → 数据备份"里关闭自动备份或删除云端备份；关闭后云端已有的备份仍保留，可随时删除；注销账号时备份会立即删除。

### 1.7 曲库同步（仅完整版；可选，默认开启）
完整版可以在多台设备之间保持曲库一致。**这项功能仅对已开通该功能的账号开放。**开启后，我们会在服务器保存你曲库里每个条目的这些元数据：

- 平台、视频 ID、分 P、类型（音频或视频）；
- 标题、博主、时长、来源链接；
- 入库时间，以及你最后修改它的时间；
- 你在网页端把它设为置顶的状态；
- 你在应用或网页端对这个条目做过的改名。

同步是双向的：你在手机上新增的条目会上传到你的账号；你在网页端或其他设备上做的改动（改名、删除）会同步回这台设备。

**删除也是双向的**：你在这台设备上删除一个已经同步过的条目，服务器上的对应条目会被标记为已删除，其他设备同步时会收到这次删除。删除后，服务器会保留一条"已删除"标记（里面仍有该条目的标题等字段），用来防止别的设备把这个条目又传回来；这条标记在注销后随账号数据（冷静期满时）一并删除。如果某台设备收到删除时选择保留本机文件，那条目就只留在这台设备上，不再参与同步。

**如果条目是在网页端提取的，服务器上还会多存这些字段**：封面地址、文件大小、校验值、文件在服务器上的存放位置、缓存到期时间、最近一次访问时间。这些是网页端播放与缓存需要的；曲库同步不上传它们，也不拿它们做任何判断（接口返回的内容里即便带着，同步也会忽略）。如果这个条目在网页端保留了文件，音频/视频文件本身也保存在服务器上。

**整理信息也会同步**：你为条目打的收藏、所属类别（含类别名称与层级），以及条目所在的播放列表（含列表名称与顺序）。类别与播放列表按名称对应——两台设备上同名的类别或播放列表会被视为同一个。删除一个类别或播放列表只影响归类关系，不会删除条目本身，也不会删除音频/视频文件。

**不包含**：文件在本机的路径、平台 Cookie 与登录凭据、设备标识。曲库同步本身不传输任何音频/视频文件。
（条目清单本身仍由 §1.6 的备份负责，两者范围不同：备份恢复的是"有哪些条目"，同步保持的是"这些条目在几台设备上怎么摆"。）

你可以在"我的 → 数据备份"里关闭曲库同步；关闭后不再上传、也不再拉取，但**服务器上已经存在的条目不会自动删除**——需要你在网页端删除条目，或者注销账号。退出登录也会立即停止同步。

免费版没有曲库同步功能。

## 2. 我们为什么使用这些信息

| 用途 | 对应信息 |
|---|---|
| 提供注册、登录、多设备管理、账号找回 | 账号信息、设备与登录信息 |
| 保护账号与服务安全，防止滥用 | 登录 IP、会话信息、限流记录 |
| 了解用户规模，修复兼容问题 | 活跃信息、版本、设备型号 |
| 提供曲库清单备份与恢复 | 曲库清单（标题、博主、类别、播放列表及顺序等，不含音频文件） |
| 在多台设备与网页端之间保持曲库一致（仅完整版，且仅限已开通的账号） | 曲库条目元数据（平台、视频 ID、分 P、类型、标题、博主、时长、来源链接、入库与修改时间）、收藏、所属类别与播放列表归属；在网页端提取的条目另含封面与文件信息 |
| 处理你的反馈、定位并修复问题 | 反馈内容、诊断信息 |
| 履行法律义务 | 按法律要求保存的必要记录 |

我们不会出售你的信息，也不会用于广告或画像。

## 3. 信息存放在哪里、给谁

3.1 信息存放在中华人民共和国境内的服务器上（腾讯云）。
3.2 为了能把你的反馈送到运营者手上，反馈内容会通过 QQ 邮箱（腾讯提供的邮件服务）转发给运营者。
3.3 为了在服务器故障或误操作时恢复服务，服务器每天对数据库做一次快照，保存在同一台服务器的受限目录中，不会传输到其他地方，保留 7 天。
3.4 曲库清单备份与账号数据存放在同一台服务器的数据库中，每账号最多 3 份，与其他账号按账号隔离。
3.5 曲库同步的条目与账号数据存放在同一台服务器的同一个数据库中，**严格按账号隔离**：你只能看到、也只能同步自己账号下的条目。
3.6 除上述情形外，我们不会向任何第三方提供你的个人信息，法律法规要求或有权机关依法要求的除外。

## 4. 保存多久

| 信息 | 保存期限 |
|---|---|
| 账号信息、设备与登录信息 | 账号存续期间 |
| 活跃信息、安全日志 | 最长 30 天 |
| 曲库清单备份 | 每账号保留最近 3 份，直到你删除或注销账号；注销时立即删除（不等冷静期） |
| 曲库同步的条目 | 直到你删除该条目或注销账号。删除后保留一条"已删除"标记（含该条目的标题等字段），用于让其他设备确认这次删除；注销后随账号数据在冷静期满时删除。条目上的收藏、类别与播放列表归属随条目一并保存与删除 |
| 反馈文字（含诊断） | 180 天 |
| 反馈图片 | 90 天 |
| 注销后的账号数据 | 提交注销后有 7 天冷静期，期满后删除 |
| 服务器快照中的数据 | 最长 7 天，随快照滚动覆盖而清除；恢复快照时会重新执行删除，已注销的账号不会恢复 |
| 注销台账 | 仅保留账号编号（一串随机字符）和删除时间，不含登录名等其他信息，用于防止恢复快照时已注销的账号重新出现；长期保留 |

法律法规要求更长保存期的，从其规定。

## 5. 你的权利

- **查看与管理**：在"我的 → 账号与安全"查看设备和登录情况，退出其他设备，修改密码。
- **注销**：在同一页面输入密码即可注销。注销后，**云端备份立即删除；曲库同步的条目与其余账号数据一起，在 7 天冷静期满后删除**。
- **曲库清单备份**：在"我的 → 数据备份"关闭自动备份、立即备份或删除云端备份。
- **曲库同步**：在同一页关闭同步；关闭后不再上传与拉取。**你在应用里删除一个已经同步过的条目时，服务器上的对应条目也会被标记为已删除，其他设备会同步到这次删除。**收藏、类别与播放列表的改动同样会在多台设备之间同步。想一次清空服务器上的全部条目，请在网页端删除，或注销账号。
- **更正、删除、了解**：你可以通过"联系作者"提出请求，我们会在合理期限内处理。
- **撤回同意**：你可以随时停止使用并注销账号。

## 6. 我们如何保护信息

密码使用加盐的单向哈希；登录令牌在服务器上只保存其哈希；通信使用 HTTPS；快照存放在受限目录；对接口做权限校验与限流，同步接口只对登录账号开放并按账号校验归属。但没有任何系统是绝对安全的。发生个人信息安全事件时，我们会依法通知你并采取补救措施。

## 7. 未成年人

本服务不面向未满 18 周岁的人。如果我们发现收集了未成年人的信息，会尽快删除。

## 8. 本说明的变更

我们可能修订本说明。重要变更会在应用内提示，并在你下次登录时请你重新确认。
