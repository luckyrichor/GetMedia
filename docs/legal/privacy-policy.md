# GetMedia 隐私说明

版本：v1　生效日期：2026 年 10 月 30 日


洛尘（以下称"我们"）是 GetMedia（Android 应用和网页端）的运营者。本说明告诉你：我们收集什么、为什么收集、放在哪里、保存多久，以及你可以怎么处理。

## 1. 我们收集哪些信息

### 1.1 账号信息
- **登录名**：你注册时自己起的名字。
- **密码**：我们只保存经过单向加密（哈希）的结果，不保存明文，也无法查看你的密码。
- **恢复码**：只保存其校验值，不保存明文。
- **同意记录**：你同意用户协议和隐私说明的版本和时间。

### 1.2 设备与登录信息
- 设备型号、系统版本、应用或网页版本、渠道（Android 或网页）。
- 登录时间、最近登录的 IP 地址、会话的创建和最近使用时间。
- **每天最多一次的活跃信息**：版本、系统、设备型号，用于了解有多少人在使用以及修复兼容问题。

### 1.3 你主动提交的反馈
当你使用"联系作者"，我们会收到你填写的文字、你选择上传的图片（最多 3 张）、你填写的联系方式（可选），以及在你勾选"附带诊断信息"后发送的诊断内容。你可以在发送前点击"查看将发送的内容"，看到将会发送的全部字段。

诊断内容只包含：应用或网页版本、系统、设备型号、渠道，以及最近若干步骤的状态码、耗时和阶段。**不包含**密码、Cookie、登录令牌，也不自动包含你提取的链接或分享文本。

我们会清除图片中的位置等元数据（EXIF）。请不要在文字或图片中提交密码等敏感信息。

### 1.4 网页端
网页端使用必要的会话 Cookie 保持登录，不使用广告或第三方统计。

### 1.5 我们不收集的信息
手机号、真实姓名、身份证件、通讯录、短信、精确位置、设备唯一标识（如 IMEI）、你设备上的媒体文件内容、你保存的播放列表和类别。这些内容保存在你自己的设备上。

## 2. 我们为什么使用这些信息

| 用途 | 对应信息 |
|---|---|
| 提供注册、登录、多设备管理、账号找回 | 账号信息、设备与登录信息 |
| 保护账号与服务安全，防止滥用 | 登录 IP、会话信息、限流记录 |
| 了解用户规模，修复兼容问题 | 活跃信息、版本、设备型号 |
| 处理你的反馈、定位并修复问题 | 反馈内容、诊断信息 |
| 履行法律义务 | 按法律要求保存的必要记录 |

我们不会出售你的信息，也不会用于广告或画像。

## 3. 信息存放在哪里、给谁

3.1 信息存放在中华人民共和国境内的服务器上（腾讯云）。
3.2 为了能把你的反馈送到运营者手上，反馈内容会通过 QQ 邮箱（腾讯提供的邮件服务）转发给运营者。
3.3 为了在服务器故障或误操作时恢复服务，服务器每天对数据库做一次快照，保存在同一台服务器的受限目录中，不会传输到其他地方，保留 7 天。
3.4 除上述情形外，我们不会向任何第三方提供你的个人信息，法律法规要求或有权机关依法要求的除外。

## 4. 保存多久

| 信息 | 保存期限 |
|---|---|
| 账号信息、设备与登录信息 | 账号存续期间 |
| 活跃信息、安全日志 | 最长 30 天 |
| 反馈文字（含诊断） | 180 天 |
| 反馈图片 | 90 天 |
| 注销后的账号数据 | 提交注销后有 7 天冷静期，期满后删除 |
| 服务器快照中的数据 | 最长 7 天，随快照滚动覆盖而清除；恢复快照时会重新执行删除，已注销的账号不会恢复 |
| 注销台账 | 仅保留账号编号（一串随机字符）和删除时间，不含登录名等其他信息，用于防止恢复快照时已注销的账号重新出现；长期保留 |

法律法规要求更长保存期的，从其规定。

## 5. 你的权利

- **查看与管理**：在"我的 → 账号与安全"查看设备和登录情况，退出其他设备，修改密码。
- **注销**：在同一页面输入密码即可注销，注销后你的反馈也会一并删除。
- **更正、删除、了解**：你可以通过"联系作者"提出请求，我们会在合理期限内处理。
- **撤回同意**：你可以随时停止使用并注销账号。

## 6. 我们如何保护信息

密码使用加盐的单向哈希；登录令牌在服务器上只保存其哈希；通信使用 HTTPS；快照存放在受限目录；对接口做权限校验与限流。但没有任何系统是绝对安全的。发生个人信息安全事件时，我们会依法通知你并采取补救措施。

## 7. 未成年人

本服务不面向未满 18 周岁的人。如果我们发现收集了未成年人的信息，会尽快删除。

## 8. 本说明的变更

我们可能修订本说明。重要变更会在应用内提示，并在你下次登录时请你重新确认。
