## 2. free / full dex 反编译扫描

### 2.1 命令

```sh
cd /Users/lc/Project/GetMedia
rm -rf .run-tmp/dex && mkdir -p .run-tmp/dex/free .run-tmp/dex/full
unzip -o -q android/app/build/outputs/apk/free/debug/app-free-debug.apk 'classes*.dex' -d .run-tmp/dex/free
unzip -o -q android/app/build/outputs/apk/full/debug/app-full-debug.apk 'classes*.dex' -d .run-tmp/dex/full

for k in CreatorBatchScreen com/getmedia/app/data/creator v2/creators creators/preview; do
  echo -n "$k -> free:"; cat .run-tmp/dex/free/*.dex | grep -a -o -F "$k" | wc -l
  echo -n "          full:"; cat .run-tmp/dex/full/*.dex | grep -a -o -F "$k" | wc -l
done

/tmp/gm-venv/bin/python tools/scan_forbidden.py heavy .run-tmp/dex/free
```

### 2.2 结果

| 关键字 | free dex | full dex |
|---|---|---|
| `CreatorBatchScreen`（页面类） | **0** | 368 |
| `com/getmedia/app/data/creator`（批量数据层包名） | **0** | 78 |
| `v2/creators`（服务端接口路径） | **0** | 1 |
| `creators/preview` | **0** | 1 |

```
=== heavy 禁用词扫描 ===
free:  禁用词扫描（heavy）通过          (exit 0)
full:  4 个文件命中（预期：完整版应当包含这些重型标识）
       .run-tmp/dex/full/classes7.dex:16948: 命中禁用词表第 35 行
       .run-tmp/dex/full/classes8.dex:1285:  命中禁用词表第 7 行
       .run-tmp/dex/full/classes8.dex:1279:  命中禁用词表第 35 行
```

计数口径：对 `classes*.dex` 的原始字节按固定子串计数（`grep -a -o`），因此统计的是字符串池/类型名/方法名中的出现次数，而不是"类个数"。

### 2.3 本轮修掉的一处扫描噪音

首轮扫描时 free dex 有 2 处命中 `CreatorBatch`（禁用词表第 35 行）：来源是 `main` 里 `OwnerGate` 接缝的**方法名** `CreatorBatch` 与属性 `creatorBatch`（免费版只有占位实现，没有页面类）。虽然 `CreatorBatchScreen` 仍是 0，但保留"命中"会让"free 产物零重型标识"这条证据变模糊。

处理：把接缝成员改名为 `BatchExtract` / `batchExtract`（只改 `main`/`free`/`full` 三个 `OwnerGate.kt` 与 `ExtractScreen.kt` 调用点，行为不变），重建后 free 的 heavy 扫描 **0 命中、exit 0**。`full` 的命中来自真实实现，属预期。
